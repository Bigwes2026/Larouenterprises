# Larou Enterprises LLC Website

A clean, responsive static website for Larou Enterprises LLC.

## Files
- `index.html`
- `style.css`
- `script.js`
- `assets/le-logo.png`
- `assets/hero-cover.png`

## Preview locally
Open `index.html` with the VS Code Live Server extension.

## Publish with GitHub Pages
1. Copy all files into your `Larouenterprises` repository folder.
2. Commit and push the changes to GitHub.
3. Open the repository on GitHub.
4. Go to **Settings → Pages**.
5. Choose **Deploy from a branch**.
6. Select `main` and `/root`.
7. Save.

## Custom domain
In GitHub Pages, enter your domain under **Custom domain**. Then update the domain's DNS records using the values GitHub provides.
